# Coursera Assignments

Welcome to the **Coursera Assignments** repository! This repository contains my completed assignments from various Coursera data science courses. Each assignment involves real-world data analysis and machine learning techniques, showcasing my skills in exploratory data analysis (EDA), visualization, and predictive modeling.

## 📂 Repository Contents
This repository includes the following Jupyter Notebook assignments:

1. **Rain Prediction in Australia**  
   - Performed exploratory data analysis (EDA) on Australian weather data.
   - Built machine learning models to predict whether it will rain tomorrow.
   - Used feature engineering and model evaluation techniques.

2. **House Sales in King County, USA**  
   - Analyzed housing prices in King County using Python.
   - Applied regression techniques to predict house prices.
   - Visualized key trends and performed feature selection.

3. **Data Science Ecosystem**  
   - Explored fundamental concepts of the data science field.
   - Created a summary of key tools, languages, and libraries used in data science.

4. **Analyzing Historical Stock and Revenue Data**  
   - Collected and analyzed historical stock prices and revenue data of major companies.
   - Used visualization techniques to interpret stock trends.
   - Cleaned and processed financial datasets for insights.

## 🛠️ Technologies Used
- **Programming Language**: Python
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Tools**: Jupyter Notebook, Coursera Labs
